# 当前 Redis 实现

Redis 用于商品元数据缓存和两级 Lua 固定窗口限流，不扣库存、不存交易余额。库存、状态和售价每页批量查 MySQL；详情为单条非锁定快照查询。

元数据使用 JSON 字符串，key 为 blindbox:catalog:metadata:v2:<generation>:<条件>，条目 TTL 120 秒。建池、编辑、状态变化在事务提交后向有界单线程执行器提交版本失效任务；抽奖/补货不失效元数据。相同锁条带的缓存缺失合并加载，最多等 50ms；缓存 Redis 故障进入 1 秒冷却后回源。

入口限流在 JWT 查询数据库前执行：默认同来源认证20/min、读6000/min、其他写120/min。认证后用户额度为抽奖10/min、充值5/min、上传6/min、其他写30/min。Lua 计数饱和至 limit+1，修复缺失 TTL，60 秒到期，多实例共享额度。

限流开启时 Redis 故障阻止写请求并返回503，读请求回源但仍有本机并发保护。RATE_LIMIT_ENABLED=false 只关闭 Redis 额度，不关闭 HTTP/抽奖准入。代理来源识别、配置、指标和验证步骤见 [并发优化说明](../../docs/并发优化说明.md)。
